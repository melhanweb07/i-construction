# I Construction Admin Panel

A premium frontend admin panel for the I Construction website, built with Next.js and TypeScript.

## Features

- Secure frontend-only demo authentication
- Dashboard overview with key business metrics
- Construction and real-estate management
- Service, project, property, blog and media administration
- Enquiry review and status updates
- Website content controls and FAQ management
- Chatbot knowledge management
- Admin users and settings
- LocalStorage persistence for all mock data

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Notes

- This is a frontend-only admin panel using realistic mock data and localStorage.
- Authentication is demo-only and should be replaced with secure backend authentication before production.
- API modules are structured and ready for future backend integration with a Node.js/Express and PostgreSQL stack.
